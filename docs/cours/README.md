# Cours du projet

Un document par lot livré. Chacun explique ce qui a été fait, pourquoi, et comment, à un lecteur qui débute en data science.

Ces documents ne remplacent pas les références du projet, `decisions.md`, `data-contract.md` et `resultats.md`, qui restent la source de vérité. Ils racontent le chemin : le problème de départ, les notions nécessaires pour le comprendre, les choix faits, les erreurs rencontrées et ce qu'elles ont appris.

## Règles d'écriture

- Partir du problème concret avant la technique.
- Définir chaque terme technique à sa première apparition, sans supposer qu'il est connu.
- Illustrer par les vrais chiffres mesurés sur le projet, jamais par des chiffres inventés.
- Raconter les erreurs commises et comment elles ont été détectées. C'est souvent là que se trouve la leçon.
- Terminer par ce qu'il faut retenir, en quelques points.
